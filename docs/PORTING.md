# Перенос логики Desktop → Android

Сверено с `Telegram/SourceFiles/mokagram/` в Desktop. Функции переносятся на Java и Android UI; Qt/C++ desktop-код нельзя включить в Android-приложение напрямую. Здесь «реализовано» означает наличие интеграции в исходниках, а не подтверждение поведения на устройстве.

| Модуль Desktop | Состояние Android |
| --- | --- |
| Настройки | Локальные SharedPreferences, экран в Settings → Mokagram, ключи `ghost.*` сохранены. Экспорт/импорт `.mokaset` ещё не перенесён. |
| Призрак | Глобальный переключатель, четыре флага, одноразовый offline, расписание с отдельными флагами. Основные read/typing/story пути проверяют режим до изменения состояния; сетевой фильтр страхует обычные read RPC и заменяет online на offline. |
| Исключения и «Прочитать сейчас» | Ещё не перенесены. Desktop PeerId нельзя напрямую считать Android dialogId. |
| Скрытие заблокированных | Ещё не перенесено. |
| Режим стримера | Ещё не перенесён. Нужны маски полей, уведомлений, копирования и проверка всех экранов Android. |

| Музыка, SoundCloud, тексты песен | Ещё не перенесены. Стандартный музыкальный плеер Telegram остаётся основой. |
| Плагины, магазин, Python API | Ещё не перенесены. Desktop Python/Qt API не совместим с Android. |
| Сниппеты и команды | Ещё не перенесены. |
| Цитаты, Saveinator, сведения о сообщении | Ещё не перенесены. |
| Scam, дата регистрации, ping, Stars-статистика | Ещё не перенесены. |

## Отличия начального «Призрака»

Настройки общие для установки, как desktop-реестр, а не для отдельного аккаунта. Расписание вычисляется по времени устройства при каждой проверке, начало включительно, конец исключительно, одинаковые времена означают выключенный интервал. Флаги расписания дополняют активные ручные флаги, не заменяют их.

В режиме скрытия прочтений чат сохраняет непрочитанное состояние. Заблокированные сетевые запросы завершаются локальной ошибкой `MOKAGRAM_GHOST_SUPPRESSED`, не фиктивным ответом сервера. При скрытии статуса online превращается в offline; отправка обычных сообщений всё равно может выдавать активность на стороне Telegram. Просмотр собственных историй и счётчики при активном скрытии также не отмечаются локально.

Требуют отдельной проверки: секретные чаты, исчезающие медиа и TTL, уведомления и ответы с часов, Android Auto, потоки обсуждений, отложенные операции, включение/выключение расписания при свёрнутом приложении. Скрытие сервисного read-сообщения секретного чата может влиять на запуск таймера у собеседника; до проверки не считать этот сценарий готовым.

## Проверка на устройстве

1. С выключенным режимом проверить вход, переписку, read receipts, typing, истории и звонки.
2. Включить каждый флаг отдельно; проверить со второго аккаунта, что соответствующие события не отправляются и остальные работают.
3. Повторить с двумя активными аккаунтами и после перезапуска.
4. Проверить границы дневного/ночного расписания, переходы времени и выключенный основной переключатель.
5. Проверить секретные чаты и таймеры на тестовых данных до обычного использования.
6. Проверить установку рядом с Telegram, уведомления, ссылки и обновление APK с тем же ключом подписи.
